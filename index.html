Apex exercises in the browser

A sample page that embeds aer, the Apex Execution Runtime, compiled to WebAssembly. Your code runs in this browser tab against an empty in-memory org; nothing is sent to a server. View this page's source to see how it works: all of its JavaScript is in one script at the bottom, and it talks to the runtime through aer-worker.js.
